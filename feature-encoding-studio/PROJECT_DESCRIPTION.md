# Project description (for submission)

**Title:** Feature Encoding in Machine Learning: Animated Educational Videos
**Author:** Nitish Bhardwaj
**Course context:** Applied Machine Learning

This project explains three techniques for converting categorical variables into model-ready numerical
representations: label encoding, one-hot encoding, and ordinal encoding. It consists of four silent, fully
programmatic motion-graphics videos (three topic videos and one comparison and decision guide), produced with
TypeScript, React and Remotion. Each video progresses from beginner concepts (what a categorical variable is,
nominal versus ordinal data) to more advanced points (misleading ordinal relationships, high-cardinality features,
sparse matrices, the dummy variable trap, unseen categories, and order versus distance).

All explanations appear as on-screen text synchronised with animated tables, number lines, vectors, staircases,
sparse matrices and a decision tree, so the videos work without sound. The Python examples use scikit-learn and were
executed to confirm that the outputs shown on screen are the library's real outputs. All visuals are original and
generated by code; no external footage, music, or characters are used.
